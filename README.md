# Applied Statistics in R: From Data to Results

This repository contains the materials for the workshop **Applied Statistics in R: From Data to Results**.

The workshop introduces practical statistical methods used in agricultural research, with a focus on understanding statistical concepts, interpreting results, and communicating findings.

## Workshop Topics

- Data exploration
- Correlation analysis
- Linear regression
- Analysis of variance (ANOVA)
- Linear mixed models
- Nonlinear regression

## Materials

The repository contains:

- Workshop webpages
- R code examples
- Exercise files
- Workshop dataset
- Supporting materials
